SCENARIO 03 - DYNAMIC INJECTION

SP script injected on DOMContentLoaded

The SP tag is injected with document.createElement('script') on DOMContentLoaded, with no artificial delay. The script URL and the domain ID are assembled at runtime, so neither appears in the raw HTML — this is what makes the plain-HTTP pass fail and the browserless pass the only thing that can succeed.

Expected: plain-HTTP NotInstalled; browserless should catch it, since injection happens well before the network goes idle.
