SCENARIO 04 - NO SCRIPT

No SP script at all (negative control)

This page contains no Secure Privacy tag, no SP script URL, and no domain ID anywhere in its markup.

Expected: NotInstalled from both passes.

Keeping the markup clean matters: the detector returns InvalidDomain if the source merely contains the string secureprivacy.ai/script/, and CorrectlyInstalled if it merely contains the domain ID. Either one would destroy this negative control — see scenario 06.
