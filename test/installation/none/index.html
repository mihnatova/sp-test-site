SCENARIO 04 - NO SCRIPT

No SP script at all (negative control)

This page contains no Secure Privacy tag, no SP script URL, and no domain ID anywhere in its markup — neither as literal text nor as an HTML entity.

Expected: NotInstalled from both passes.

Keeping the markup clean matters more than it looks. The detector falls through to two bare substring tests: one on the SP script URL prefix (which yields InvalidDomain) and one on the domain ID (which yields CorrectlyInstalled). Either string appearing anywhere — prose, a code sample, an install guide — destroys this negative control. Writing it as an HTML entity is not enough either: the entity survives the plain-HTTP pass but is decoded back to plain text in the rendered DOM that the browserless pass inspects. See scenario 06 for the ID case.
